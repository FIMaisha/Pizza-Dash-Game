# Pizza-Dash-Game
Pizza Dash is an interactive 2D time-management cooking game built on the MIT Scratch platform. The project simulates a fast-paced kitchen environment where players act as a chef fulfilling telephone orders under strict time limits while managing dynamic UI elements and custom hand-drawn sprites. Key mechanics include click-based dough expansion logic, event-driven broadcasting for sprite coordination, layer management to prevent graphic overlapping, and a randomized fly-spawning challenge that introduces risk and reward elements through score penalties and bonuses.

To play the game, you can download the project file from this repository and open it in the offline Scratch editor or import it into the online Scratch platform, then press the green flag to start. 

First, click on the dough to make it expand; once it reaches its maximum size, it stops growing. Next, select the sauce and toppings according to the customer's order. If a fly appears in the kitchen, you must press the spacebar to get rid of it, or you will receive a penalty for an unhygienic kitchen environment. The more pizza orders you successfully complete within the given timeline, the more money you earn.
Future improvements for the project include implementing an advanced order-validation algorithm to check whether completed pizzas match specific customer requests.
